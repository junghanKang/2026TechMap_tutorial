# Safe Dial 튜토리얼 프로젝트

튜토리얼의 최종 앱을 실행할 수 있는 Xcode 프로젝트입니다. 앱에는 스크린샷
제작 모드나 수치 조절 패널 같은 개발자용 도구가 포함되지 않습니다.

## 실행 준비

- iOS 17 이상을 실행하며 ARKit을 지원하는 실제 iOS 기기가 필요합니다.
- Simulator에서도 빌드는 할 수 있지만, 기기의 앞·뒤 이동을 사용하는 체험은 실기기에서만
  확인할 수 있습니다.
- 소리와 햅틱을 확인하려면 기기의 소리를 켜세요.

## Xcode에서 실행하기

1. `safe-dial.xcodeproj`를 엽니다.
2. `safe-dial` target의 **Signing & Capabilities**에서 자신의 Team을 선택합니다.
3. 서명 충돌이 나면 Bundle Identifier `com.spatiallab.sketch007n`을 자신의 고유한 값으로
   바꿉니다. 예: `com.example.SafeDialTutorial`
4. 연결한 기기를 선택하고 Run합니다.
5. 첫 실행에서 카메라 사용을 허용한 뒤 화면 안내에 따라 시작점을 설정합니다.

## 체험 순서

시작점의 자물쇠를 열고, 기기를 앞으로 이동해 다음 자물쇠에 도달합니다. 약 10cm 간격의
세 위치에서 다이얼을 돌리며 소리와 햅틱 피드백의 변화를 확인하세요.

추적이 끊기거나 기기를 빠르게 움직였다면 화면의 **이 위치를 시작점으로**를 눌러 다시
보정하세요.
